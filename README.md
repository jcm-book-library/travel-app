# Travel Companion

A phone-first travel companion for two travellers on a Feb 2027 trip: one timeline of flights, tour days, stays and day tours, pinned meeting points, and a daily log of where we've been. Installs on a phone's home screen and opens offline (read-only).

- **Status:** planning; database design done, app not yet built.
- **Data:** Supabase (see `supabase/migrations/`). No real trip data is stored in this repo.
- **Notes for Claude and the plan:** `CLAUDE.md`.
